# Attention-Initialized Gradient-Matched Prompt Inversion Design

This document describes the TinyLlama pilot method named Attention-Initialized Gradient-Matched Prompt Inversion (AIGM-PIA). It is a white-box TinyLlama pilot, not a full reproduction of the paper's large-model experiments.

## Threat Model

The attack function receives only:

- observed boundary activation `H_obs`;
- sequence length;
- public TinyLlama prefix parameters up to the target layer;
- tokenizer;
- public vocabulary embedding matrix;
- public semantic candidates generated by TinyLlama itself.

The original prompt, original token ids, original token strings, and reference embeddings are used only outside the attack to generate `H_obs` and to evaluate final recovery.

## Existing Attention-Guided Pilot Is Not AIGM-PIA

- The previous `dummy_init` uses Stage-A optimized dummy embeddings as Stage-B initialization. It is not alpha-NN initialization.
- The previous `attention_context` uses `A_dummy @ activation` as a context loss. It is not an initialization method.
- The previous `attention_gradient` performs gradient fusion between reconstruction losses. It is not Gradient-Direction Token Matching.
- The previous `full` method in `pia_attention_guided.py` is not renamed or treated as AIGM-PIA.

`pia_tinyllama.py` and `pia_attention_guided.py` are intentionally left unchanged.

## Stage A: Dummy-Attention Proxy

Continuous dummy embeddings `D` are optimized against:

`L_dummy = MSE(F_prefix(D), H_obs) + lambda_dummy * L_vocab(D)`

The target layer self-attention is extracted from the optimized dummy pass:

`A_self = MeanHead(Attention_target_layer(D*))`

`A_self` is detached before Stage B. It is recorded only as a dummy-attention proxy, not true prompt attention. The implementation checks row normalization, causal upper-triangular masking, entropy, sparsity, and BOS-column mass.

## Stage B: Alpha-NN Initialization

Direct alpha-NN initialization uses:

`H_alpha = A_self @ H_obs`

`t0_i = NN_W(H_alpha_i)`

`z0_i = E(t0_i)`

The residual version uses:

`H_alpha_residual = (1 - gamma) * H_obs + gamma * (A_self @ H_obs)`

`A_self @ H_obs` is the only valid multiplication direction here because attention weights operate over sequence positions: `[seq_len, seq_len] @ [seq_len, hidden_dim]`. `H_obs @ A_self` would mix the hidden dimension with a sequence matrix and is dimensionally wrong for this purpose.

The direct version is a strict formula experiment. Because `H_obs` is a deep hidden state rather than input embedding space, the residual version is treated as the main candidate.

## Stage C: Gradient-Direction Token Matching

After AdamW optimization of continuous embeddings, AIGM-PIA computes the attack-side reconstruction gradient:

`g_i = grad(L_rec, z_i)`

where:

`L_rec = L_act + lambda_vocab * L_vocab + lambda_context * L_context`

`L_act = MSE(F_prefix(z), H_obs)`

`L_context = MSE(A_self @ F_prefix(z), A_self @ H_obs)`

For each position, candidates combine nearest tokens from optimized `z_i`, nearest tokens from `H_alpha_residual_i`, TinyLlama semantic candidates from the recovered prefix, and the initial alpha-NN token. The selected token maximizes:

`eta * normalized_gradient_score + (1 - eta) * normalized_calibration_score`

The gradient score is `cosine(E(w) - z_i, -g_i)`. This is Gradient-Direction Token Matching, not recovered ground-truth training gradient matching.

## Planned Pilot

The pilot runs on Skytrax-28 with participant number 4, attacker position 4, and target layers 17 and 19. The first validation uses 2 samples, epoch 100, stage-A epoch 100, seed 42, K=10, Y=10, eta=0.5, gamma=0.3.

All outputs are written under `runs/alpha_gm_pilot/`.
