# RAP-FINAL Prompt Inversion Method

Clean package for the RAP-FINAL white-box prompt inversion method.

Included: main RAP-FINAL code, direct shared helpers, runner, test, design/report/audit notes, lightweight `runs/rap_final` summaries, and small data/split files needed for reproduction.

Excluded: AIR, P4, MTS, CAGDM, SACR, RAP-v2, RAP-error-rel, raw prediction logs, and large generated outputs.

Main entry point:

```bash
bash scripts/run_rap_final.sh --help
```
